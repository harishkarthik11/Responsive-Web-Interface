# Responsive Web Interface - DecodeLabs Project 1

Welcome to **Project 1: The Responsive Architecture**, a responsive web application built as part of the DecodeLabs Full Stack Internship Program.

## 🚀 Overview

This project serves as a strategic execution framework focusing on pure foundational technologies: HTML5, CSS3, and Vanilla JavaScript. The primary goal is to create a digital experience that honors the mobile-first paradigm without relying on heavy frameworks like React, Tailwind, or Bootstrap.

## 🛠️ Built With

*   **HTML5**: Semantic integrity (landmarks like `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
*   **CSS3**: Mobile-First strategy using CSS Grid for macro layouts and Flexbox for micro-components. Incorporates fluid typography using `clamp()`.
*   **JavaScript**: Vanilla JS for state management and interactivity (e.g., mobile navigation toggle, save buttons, smooth scrolling).

## ✨ Features

*   **Fully Responsive**: Adapts seamlessly to Mobile, Tablet (768px+), and Desktop (1024px+) viewports.
*   **2025 Aesthetics**: Utilizes a warm, grounded color palette consisting of Mocha Mousse (`#A5856F`), Ethereal Blue (`#A0D4E0`), and Moonlit Grey (`#F2F0EA`).
*   **Interactive Elements**:
    *   Smooth scrolling across internal links.
    *   Dynamic "Save" bookmark buttons on content cards.
    *   Interactive bottom navigation bar for mobile devices.
    *   Accessible hamburger menu for responsive navigation.

## 📂 Project Structure

```text
├── index.html   # Main structure and semantic landmarks
├── style.css    # Responsive styling, Grid/Flexbox architecture, and fluid typography
└── script.js    # Interactive logic and DOM manipulation
```

## 💻 Getting Started

To view this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/harishkarthik11/Responsive-Web-Interface.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Responsive-Web-Interface
   ```
3. Open `index.html` in your favorite web browser.
